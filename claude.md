# Bible MCP Server

## Project Overview
A local MCP server providing Bible study tools to Claude via FastMCP.
SQLite backend pre-loaded with scripture text parsed from OSIS XML source files.

## Stack
- Python 3.11+ (on macOS, use Homebrew Python — system Python does not support SQLite extensions)
- FastMCP (https://github.com/jlowin/fastmcp)
- SQLite 3.41+ (built-in, no external DB)
- FTS5 for full-text search (built into SQLite)
- sqlite-vec for vector/semantic search
- sentence-transformers for generating embeddings (model: all-MiniLM-L6-v2)

## Data Source
OSIS XML files from: https://github.com/bzerangue/osis-bibles

- Primary: `en/web.xml` (World English Bible — fully public domain)
- Secondary: `en/kjv.xml` (King James Version — fully public domain)

Do not research alternative Bible data sources. Use only the above.
Do not use any external Bible APIs.

## Database Schema
Design the schema to support multiple translations from day one,
even though we are only loading WEB initially.

Tables:
- `translations` — id, abbreviation, name, language, license
- `books` — id, translation_id, osis_id, name, testament, book_order
- `verses` — id, translation_id, book_id, chapter, verse, text
- `verses_fts` — FTS5 virtual table over verses.text
- `verse_embeddings` — vec0 virtual table (sqlite-vec) for semantic search

Use OSIS book IDs (e.g. Gen, Exod, Matt) as canonical identifiers.

## MCP Tools to Implement

1. `get_verse(translation, book, chapter, verse)`
   Exact reference lookup. Returns the verse text and metadata.

2. `get_passage(translation, book, chapter, verse_start, verse_end)`
   Range lookup. Returns a list of verses.

3. `search_text(translation, query, limit=10)`
   FTS5 full-text search across verse text.

4. `search_semantic(query, translation="web", limit=10)`
   Vector similarity search via sqlite-vec.
   Embeds the query using sentence-transformers (all-MiniLM-L6-v2)
   and returns the closest matching verses.

5. `list_translations()`
   Returns all available translations in the database.

6. `list_books(translation)`
   Returns all books for a translation with testament grouping.

## Instructions for Claude Code
- Use /plan before executing any multi-step task
- Do not use hardcoded raw GitHub URLs — clone or inspect the repo structure at runtime
- Do not install unnecessary dependencies
- ingest.py must be idempotent (safe to re-run without duplicating data)
- Embedding generation during ingest will be slow — add a progress indicator
- All MCP tool responses must return plain dicts, not custom objects
- Keep server.py focused — helper logic lives in a separate db.py or similar module
- On macOS, sqlite-vec requires Homebrew Python; add a startup check that
  confirms sqlite_vec can be loaded and prints a clear error if not

## Notes
- The all-MiniLM-L6-v2 model produces 384-dimensional embeddings
- Embed at the verse level (not chapter or passage level)
- Pre-compute all embeddings during ingest; do not embed at query time except for the query itself
- KJV can be ingested later with the same ingest.py script; schema must support it from day one
